MONEY PLAN V3

V3 is based on the user's real financial cycle:
25th of one month through the 24th of the next month.

CORE MODEL
- Salary/main income
- Previous-cycle leftover (carry-in)
- Other income such as Kindergeld
- Permanent recurring commitments
- Limited-duration installments
- Per-cycle variable amounts: Visa, 3oshour, spontaneous
- One-off expenses such as PayPal Later
- User Revolut savings contribution
- Wife Revolut contribution (default EUR 1,500, editable)
- University savings goal: EUR 72,000 by September 2028

SAVINGS
Revolut savings reduces cash available for the cycle, but is tracked separately as savings.
The app shows progress, contribution history, required average contribution and trajectory status.

MIGRATION
On first launch V3 attempts to migrate data from the V2 localStorage key. Export a backup before replacing your live files.

DEPLOYMENT
Replace the files in the same GitHub Pages repository with the contents of this folder, keeping the icons folder. The existing Pages URL can stay the same.
After replacing files, do a hard refresh on desktop (Ctrl+Shift+R) or close/reopen the installed iPhone PWA.

IMPORTANT
Data is stored locally in the browser/device. Export backups regularly.
